    Methodology

    Every day at 06:00 UTC, a scheduled workflow (GitHub Actions) launches an OpenCode agent with web search enabled. The agent researches the latest AI capability news and writes a JSON verdict — no, not_yet, or yes — with confidence, a rationale, and cited sources. When it changes, the repo commits it and this page re-renders. This is honest, vibes-free, and occasionally wrong.
